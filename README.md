# IDMohendi


برنامج تحميل لويندوز بنفس الفكرة وأهم الميزات، بدون تسجيل ولا رقم سري ولا تحديثات مزعجة.

## الميزات
- **تحميل متعدد الاتصالات**: يقسم الملف لأجزاء ويحملها بالتوازي (حسب عدد الاتصالات في الإعدادات).
- **إيقاف واستئناف**: الحالة تُحفظ على القرص، فتكمل بعد إغلاق البرنامج أو إعادة تشغيل الجهاز.
- **إعادة المحاولة التلقائية** عند انقطاع الاتصال مع تأخير متزايد.
- **قائمة انتظار**: حد أقصى للتحميلات المتزامنة.
- **جدولة**: تحديد وقت بدء التحميل.
- **تكامل مع Chrome**: يلتقط التحميلات ويرسلها للبرنامج، مع كوكيز الموقع لدعم الملفات التي تحتاج تسجيل دخول.
- **زر على الفيديوهات**: يظهر زر "FreeDM" فوق أي فيديو في الصفحة له رابط مباشر، ويرسله للبرنامج. الزر لا يعمل على يوتيوب ولا على الفيديوهات المشفّرة.

## التشغيل من الكود
```
pip install -r requirements.txt
python run_fdm.py
```

## بناء ملف exe
شغّل `build_windows.bat` وسيظهر الملف في `dist\FreeDM.exe`.

## تثبيت إضافة Chrome
1. افتح `chrome://extensions` وفعّل **وضع المطور**.
2. اضغط **تحميل إضافة غير مضغوطة** واختر مجلد `extension`.
3. من إعدادات الإضافة ضع **المنفذ** و**التوكن** (تجدهما في إعدادات FreeDM).

التوكن يمنع أي موقع آخر من إرسال تحميلات للبرنامج بدون علمك. الخادم يعمل على `127.0.0.1` فقط.

## ملاحظات
- الكوكيز تُستخدم في الذاكرة فقط ولا تُحفظ على القرص. لذلك التحميل المتوقف الذي يحتاج تسجيل دخول قد يفشل بعد إعادة تشغيل البرنامج؛ حينها أعد التقاط الرابط من المتصفح.
- لا يدعم البرنامج تحميل الفيديوهات من YouTube ولا من المواقع التي تخفي الفيديو خلف مشغّل مشفّر، وهذا مقصود.
